How it works

You don't read every diff. It does.

Coding agents are fast and confident, and the mistakes that slip through are the quiet ones: a guard deleted while "simplifying", an error swallowed, a function that now does something other than what you asked.

1

Claude edits

Every successful Edit, Write and NotebookEdit in the turn is recorded, subagents' too, as the diff Claude Code itself produced, with line numbers.

2

Haiku reviews

When the turn ends, the diff and your request go to Haiku 5.5. It runs in the background; the next turn doesn't wait.

3

One line, then your call

The verdict is pinned under the prompt. A warning opens a band with Details, Ask Claude to fix and Dismiss.

What it flags

Problems that hurt. Not opinions.

The reviewer answers one question: did this change break something? It is told never to invent a problem, and a reply it can't parse never counts as a warning.

Flags

  • A removed check, guard or error handling
  • A bug the diff introduces
  • A broken contract with callers
  • A security hole or a committed secret
  • Data loss, leftover debug code
  • Logic that doesn't do what you asked

Leaves alone

  • Style, naming, formatting
  • Missing tests
  • Anything the diff doesn't show
  • Matters of taste
Cost

A hundred reviews for about ten cents.

Haiku 5.5 costs $0.10 per million input tokens and $0.50 per million output, about 40× less than Opus. The session's running total is in the line itself.

TurnDiff sentReview
A one-function fix~2K tokens~$0.0003
A typical feature turn~6K tokens~$0.0008
A big refactor (cut at 24K characters)~8K tokens~$0.001

Want a deeper pass? /second-opinion model sonnet reviews with Sonnet 5.5 at about twenty times the price.

Commands

Four words to remember.

/second-opinion

The last review

Every finding with file and line, the model and what it cost.

/second-opinion fix

Hand it to Claude

"Check whether it is real; fix it if so, say why not otherwise."

/second-opinion off · on

Pause and resume

Remembered across sessions.

/second-opinion model

haiku or sonnet

Cheap and quick, or careful.

privacy

Your own session

The diff goes to Claude through your Claude Code session's own connection. Nothing else leaves the machine.

no setup

No keys, no Node

It runs inside Claude Code. No API key, no Python, no config file.

Install

Two commands. Then restart Claude Code.

claude plugin marketplace add egorfedorov/second-opinion
claude plugin install second-opinion@second-opinion

# after a turn that changed code
